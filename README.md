# Maze Solver using A* Search

## Overview
This project implements the A* Search algorithm to find the shortest path in a maze using the Manhattan Distance heuristic.

## Features
- Find the shortest path using A* Search
- Uses Manhattan Distance heuristic
- Displays the shortest path
- Console visualization using '*' symbol
- Handles cases where no path exists

## Project Structure
- main.py – Runs the program
- astar.py – Implements the A* algorithm
- maze.py – Stores the maze
- utils.py – Helper functions

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Nupursharma4114/Maze_Solver_AStar.git
   ```

2. Open the project folder.

3. Run:
   ```bash
   python3 main.py
   ```

## Sample Output

- Shortest Path
- Maze with '*' marking the shortest path
